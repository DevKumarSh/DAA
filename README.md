# DAA (Design and Analysis of Algorithms) Practice

This repository contains C implementations of standard Design and Analysis of Algorithms (DAA) problems:

- **Binary Search**: `BinarySearch.c`
- **Merge Sort**: `MergeSort.c`
- **Quick Sort**: `QuickSort.c`
- **0/1 Knapsack Problem (Dynamic Programming)**: `KnapSackDynamic.c`
- **Fractional Knapsack Problem (Greedy Algorithm)**: `KnapsackGreedy.c`
- **Matrix Chain Multiplication (Dynamic Programming)**: `Matrix.c`
- **Naive String Matching Algorithm**: `Nvine.c`
